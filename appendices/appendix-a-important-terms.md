# 📎 Appendix A: Important Mathematical Terms

## A.1 Algebra and Matrices

| Term | Pronunciation | English Meaning | Hinglish Meaning |
|---|---|---|---|
| Matrix | मैट्रिक्स | Rectangular arrangement of elements | Rows-columns mein numbers |
| Element | एलिमेंट | An entry of a matrix | Matrix ke andar ek value |
| Order | ऑर्डर | Number of rows × columns | Matrix ka size |
| Diagonal | डायगोनल | Entries from top-left to bottom-right | Main tirchi line |
| Transpose | ट्रांसपोज | Interchange rows and columns | Rows ko columns banana |
| Determinant | डिटरमिनेंट | Scalar associated with a square matrix | Square matrix ki special value |
| Minor | माइनर | Smaller determinant after deletion | Row-column delete karke determinant |
| Cofactor | कोफैक्टर | Signed minor | Sign ke saath minor |
| Adjoint | एडजॉइंट | Transpose of cofactor matrix | Cofactor matrix ka transpose |
| Inverse | इनवर्स | Matrix that produces identity on multiplication | Matrix ka multiplicative reverse |
| Singular | सिंग्युलर | Matrix with determinant zero | Jiska inverse nahi hota |
| Rank | रैंक | Number of independent rows/columns | Effective independent information |

## A.2 Differential Calculus

| Term | English Meaning | Hinglish Meaning |
|---|---|---|
| Function | Rule mapping input to output | Input-output relation |
| Limit | Approached function value | Nearby value |
| Continuity | No break at a point/interval | Graph mein break nahi |
| Derivative | Instantaneous rate of change | Turant badalne ki rate |
| Tangent | Line touching curve locally | Curve ki local touching line |
| Composite function | Function inside another function | Function ke andar function |
| Implicit function | Relation where $y$ is not isolated | $y$ separately written nahi |
| Parameter | Third variable defining $x$ and $y$ | Common variable $t$ |
| Differentiable | Derivative exists | Smooth slope available |

## A.3 Integral Calculus

| Term | English Meaning | Hinglish Meaning |
|---|---|---|
| Integral | Accumulation/antiderivative | Differentiation ka reverse |
| Integrand | Function inside integral | Jise integrate karna hai |
| Antiderivative | Function whose derivative is known | Original function family |
| Indefinite integral | Integral without limits | Answer with $+C$ |
| Definite integral | Integral over fixed limits | Fixed interval ka value |
| Substitution | Change of variable | Expression ko $u$ maan lena |
| Partial fraction | Rational expression decomposition | Fraction ko simple fractions mein todna |
| Riemann sum | Rectangle-sum limit | Thin strips se area approximation |

## A.4 Complex Theory

| Term | English Meaning | Hinglish Meaning |
|---|---|---|
| Complex number | $a+ib$ | Real + imaginary number |
| Imaginary unit | $i^2=-1$ | Negative one ka formal square root |
| Conjugate | $a-ib$ for $a+ib$ | Imaginary sign reverse |
| Modulus | Distance from origin | Complex number ki length |
| Argument | Angle from positive real axis | Direction angle |
| Polar form | Magnitude-angle form | Modulus aur angle representation |
| Root of unity | Solution of $z^n=1$ | Unity ke nth roots |
