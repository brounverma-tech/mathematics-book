# 📎 Appendix G: A-Z Glossary

## A

**Adjoint:** Transpose of the cofactor matrix.  
**Amplitude:** Another name for the argument of a complex number.  
**Antiderivative:** A function whose derivative equals a given function.  
**Argument:** Direction angle of a complex number from the positive real axis.

## C

**Chain Rule:** Rule for differentiating a composite function.  
**Cofactor:** Signed minor $C_{ij}=(-1)^{i+j}M_{ij}$.  
**Column:** Vertical arrangement in a matrix.  
**Complex Number:** Number of the form $a+ib$.  
**Conjugate:** Complex number formed by reversing the imaginary sign.  
**Continuity:** Property where function value equals the nearby limit.

## D

**Definite Integral:** Integral evaluated between two limits.  
**Derivative:** Instantaneous rate of change.  
**Determinant:** Scalar value associated with a square matrix.  
**Diagonal Matrix:** Square matrix with zero non-diagonal entries.  
**Differentiation:** Process of finding a derivative.

## E

**Element:** One entry in a matrix.  
**Euler's Formula:** $e^{i\theta}=\cos\theta+i\sin\theta$.

## F

**Function:** A rule that assigns an output to each allowed input.  
**Fundamental Theorem of Calculus:** Connects definite integrals and antiderivatives.

## I

**Identity Matrix:** Square matrix with ones on the main diagonal.  
**Implicit Differentiation:** Differentiation when $y$ is not isolated.  
**Indefinite Integral:** Family of antiderivatives containing $+C$.  
**Integrand:** Function inside the integral sign.  
**Integration:** Process of finding antiderivatives or accumulation.  
**Inverse Matrix:** Matrix that produces identity when multiplied by the original.

## L

**Limit:** Value approached by a function near a point.  
**Linear Equation:** Equation whose variables have power one.

## M

**Matrix:** Rectangular arrangement in rows and columns.  
**Mean Value Theorem:** Theorem relating average chord slope and tangent slope.  
**Minor:** Determinant after deleting a selected row and column.  
**Modulus:** Magnitude/distance of a complex number.

## N

**Non-Singular Matrix:** Square matrix with non-zero determinant.  
**nth Root:** A number that produces the original number when raised to power $n$.

## O

**Order:** Matrix size written as rows × columns.

## P

**Parameter:** Variable used to define two or more related variables.  
**Partial Fraction:** Decomposition of a rational function into simpler fractions.  
**Polar Form:** Complex-number representation using modulus and argument.

## Q

**Quotient Rule:** Derivative rule for one function divided by another.

## R

**Rank:** Number of independent rows or columns.  
**Riemann Sum:** Finite sum used to define a definite integral by a limit.  
**Rolle's Theorem:** Smooth equal-endpoint theorem guaranteeing a horizontal tangent.  
**Root of Unity:** Solution of $z^n=1$.  
**Row:** Horizontal arrangement in a matrix.

## S

**Scalar Matrix:** Diagonal matrix with equal diagonal values.  
**Singular Matrix:** Square matrix with determinant zero.  
**Skew-Symmetric Matrix:** Matrix satisfying $A^T=-A$.  
**Substitution:** Change of variable used to simplify an integral.  
**Symmetric Matrix:** Matrix satisfying $A^T=A$.

## T

**Tangent:** Line having the derivative's slope at a curve point.  
**Transpose:** Matrix obtained by interchanging rows and columns.  
**Triangular Matrix:** Square matrix with zeros above or below the main diagonal.

## Z

**Zero Matrix:** Matrix whose every entry is zero.
