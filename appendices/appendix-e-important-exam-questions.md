# 📎 Appendix E: Important Exam Questions

## E.1 Unit 1 — Algebra

### Very Short Questions

1. Define matrix and order.
2. Define identity and zero matrices.
3. What is a symmetric matrix?
4. Define minor and cofactor.
5. State the condition for inverse.

### Short Questions

1. Explain types of matrices with examples.
2. State properties of transpose.
3. Evaluate a $3\times3$ determinant.
4. Find the adjoint of a matrix.
5. Explain consistency conditions using rank.

### Long/Numerical Questions

1. Prove and apply determinant properties.
2. Find inverse of a $3\times3$ matrix by adjoint method.
3. Find inverse using elementary row operations.
4. Solve three simultaneous equations by Cramer's rule.
5. Solve a system by Gaussian elimination.

## E.2 Unit 2 — Differential Calculus

### Very Short Questions

1. Define limit and continuity.
2. State the first-principle formula.
3. Write product and quotient rules.
4. Write inverse-trig derivative formulas.
5. State Rolle's theorem.

### Short Questions

1. Evaluate standard-limit problems.
2. Find an unknown constant for continuity.
3. Differentiate using chain rule.
4. Explain implicit differentiation.
5. Find a parametric derivative.

### Long/Numerical Questions

1. Find derivative from first principle.
2. Solve mixed trigonometric, exponential and logarithmic derivatives.
3. Find first and second parametric derivatives.
4. Verify Rolle's theorem.
5. Verify Lagrange Mean Value Theorem.

## E.3 Unit 3 — Integral Calculus

### Very Short Questions

1. Define antiderivative.
2. Why is $+C$ required?
3. State integration by parts.
4. What is a proper rational fraction?
5. State the Fundamental Theorem.

### Short Questions

1. Write standard integration formulas.
2. Integrate using substitution.
3. Integrate $\ln x$.
4. Write partial-fraction forms.
5. Explain even/odd definite-integral properties.

### Long/Numerical Questions

1. Solve repeated integration-by-parts problems.
2. Integrate a rational function using partial fractions.
3. Evaluate definite integrals using properties.
4. Evaluate an integral as a limit of a sum.
5. Distinguish signed area and geometric area.

## E.4 Unit 4 — Complex Theory

### Very Short Questions

1. Define complex number and conjugate.
2. Find powers of $i$.
3. Define modulus and argument.
4. State Euler's formula.
5. State De Moivre's theorem.

### Short Questions

1. Perform algebra of complex numbers.
2. Prove conjugate/modulus properties.
3. Convert rectangular to polar form.
4. Multiply and divide in polar form.
5. Write cube-root-of-unity identities.

### Long/Numerical Questions

1. Solve complex division and locus problems.
2. Apply De Moivre to compute high powers.
3. Find all nth roots of a complex number.
4. Explain the geometrical distribution of roots.
5. Find and verify roots of unity.

## E.5 High-Priority Preparation

For maximum exam coverage, first master:

1. Matrix multiplication and inverse
2. $3\times3$ determinants and Cramer's rule
3. Continuity and standard limits
4. Product, quotient, chain and implicit differentiation
5. Rolle and LMVT verification format
6. Standard integrals, substitution and by parts
7. Partial fractions and definite-integral properties
8. Polar form, De Moivre and nth roots
